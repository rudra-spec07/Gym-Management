# Mobile App / PWA DLD - Module 10: Mobile Push Notifications & FCM

This document details mobile Firebase Cloud Messaging (FCM) push receivers, notification permissions, and alert centers.

---

## 1. Functional Requirement Mapping
- Maps to Backend Module `10-notification` (`NOTIFICATION-001`, `NOTIFICATION-002`).

---

## 2. Mobile Specifications
- Registers Service Worker / FCM push token on app launch.
- Displays native push notifications for 10-day inactivity alerts and membership expiration reminders.
- Mobile alert inbox tab (`/m/notifications`).
