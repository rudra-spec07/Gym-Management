# Mobile App / PWA DLD - Module 04: Mobile Streak Flame Animations

This document details mobile streak cards, flame animations, and star score badges.

---

## 1. Functional Requirement Mapping
- Maps to Backend Module `04-streak-engine` (`STREAK-001`, `STREAK-002`).

---

## 2. Mobile Component Specifications
- `StreakFlameAnimation`: CSS keyframe animated flame rendering consecutive streak count.
- `StarBadgeCard`: Star icon card showing current score (+1 for present, -2 for missed day).
