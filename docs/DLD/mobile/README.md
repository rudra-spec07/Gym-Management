# Mobile App / PWA DLD Architecture Index

This folder contains the Mobile App / Progressive Web App (PWA) Detailed Level Design specifications across all 10 core system modules.

Each module specifies:
- Mobile-optimized layouts, PWA responsive viewports, camera API integration, offline cache handling, and native touch interactions.
- Device hardware access (Camera for attendance QR scanning, Local Storage, Native Share API).
- Direct mapping to Backend APIs (`docs/DLD/backend/`) and alignment with Frontend Web (`docs/DLD/frontend/`).
