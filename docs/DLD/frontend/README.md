# Frontend Web DLD Architecture Index

This folder contains the Frontend Web Detailed Level Design specifications across all 10 core system modules for the Next.js (App Router), TypeScript, and Tailwind CSS application.

Each module specifies:
- Component layout, page paths (`app/(user)/...`, `app/(admin)/...`), and React Server Components (RSC) vs Client Components (`'use client'`).
- UI state management, hooks, Zod form validations, and interactive visual widgets.
- Direct mapping to the corresponding Backend APIs defined in `docs/DLD/backend/`.
