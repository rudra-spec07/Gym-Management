# Frontend Web DLD - Module 08: Product Store & Admin Stock Table

This document details the frontend web storefront catalog and admin product management.

---

## 1. Functional Requirement Mapping
- Maps to Backend Module `08-product` (`PRODUCT-001`, `PRODUCT-002`).

---

## 2. Page & Component Specifications

### 2.1 Member Store (`app/(user)/store/page.tsx`)
- Grid of active products with image, price, category tag, and stock indicator.
- Filter tabs: All, Protein, Creatine, Accessories.
- "Purchase Request / Buy Now" modal.

### 2.2 Admin Inventory Management (`app/(admin)/products/page.tsx`)
- Table of products with stock quantity, price, image upload, and toggle active status.
