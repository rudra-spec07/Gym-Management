# Frontend Web DLD - Module 07: Diet Meal Schedule & Admin Creator

This document details the frontend web components for viewing assigned diets and building diet templates.

---

## 1. Functional Requirement Mapping
- Maps to Backend Module `07-diet` (`DIET-001`, `DIET-002`).

---

## 2. Page & Component Specifications

### 2.1 Member Diet Schedule (`app/(user)/diet/page.tsx`)
- Displays active assigned diet plan, target daily calories, macros (Protein, Carbs, Fats).
- Meal timeline: Breakfast, Lunch, Pre-workout, Post-workout, Dinner.

### 2.2 Admin Diet Creator (`app/(admin)/diets/page.tsx`)
- Form to add new diet templates and assign to members.
